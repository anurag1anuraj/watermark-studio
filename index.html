Watermark Tool

Supported formats: PDF, JPG / JPEG, PNG, WebP (up to 50 MB).

PDF watermarks support standard Latin characters. Images accept any text your device can display.

Pattern

For PDFs, size and spacing are in points (1/72 inch). For images, they scale with the image width so the result looks the same at any resolution. Positive rotation turns the text counter-clockwise.

Live preview

Choose a file to see a live preview here.

Your original file is never modified. The watermarked copy is downloaded as a new file. See the Privacy Policy for details.

Processed in your browser

Watermarks are drawn on your device using PDF-Lib and the HTML canvas. Selected files are not sent to our servers.

Full control

Set the text, size, colour, opacity, rotation and spacing, and choose between a repeating pattern or a single centred mark.

Original quality kept

PDF pages keep their size and content. Images keep their original dimensions and aspect ratio. Read the About page for current limitations.
